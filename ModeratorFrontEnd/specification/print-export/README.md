# Print exports

- `moderator-ux-wireframes.pdf` contains all 15 wireframes, one per A4 landscape page.
- `png/` contains one PNG per source SVG at 2x resolution for individual printing or insertion into documents.
- `index.html` is the print layout used to generate the PDF and can be opened in a browser for custom paper sizes.

For best results, print the PDF with **Fit to printable area** enabled. The three mobile wireframes are centered at their natural portrait aspect ratio rather than stretched across the page.
